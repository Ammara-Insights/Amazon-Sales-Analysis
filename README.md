# Amazon Sales Analysis
 <h1>Project Overview</h1>

This project analyzes Amazon sales data to identify sales performance, customer behavior, and business trends.
The project focuses on transforming raw sales data into meaningful insights using data analysis and visualization.

<b>Tools Used</b>

* Power Bi
* Data Cleaning
* Data Visualization
* Dashboard Design

<b>Objectives</b>

* Analyze overall sales performance
* Identify important sales trends
* Understand customer purchasing behavior
* Identify high-performing categories/products
* Present insights through an interactive dashboard

<b>Key Insights</b>

01 — Discount ≠ Higher Rating
Higher discounts do not consistently correspond to higher customer ratings. The downward trend indicates a weak negative relationship between discount percentage and rating.

02 — Category Matters
Customer ratings vary across product categories, suggesting that category-level differences may influence customer perception.

03 — Saving Varies by Category
Electronics provides the highest average customer saving per product, followed by Home & Kitchen. This shows that higher customer savings are not determined by discount percentage alone.
